## ✨ Features
- **Create Post:** Add a title and content to publish a new blog post.
- **View Posts:** All published posts are displayed with date and time.
- **Delete Post:** Remove unwanted posts with a confirmation prompt.
- **Data Persistence:** Uses SQLite database for permanent data storage (no data loss on refresh).
- **Modern UI:** Premium Glassmorphism design with dark theme.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API)
- **Backend:** Node.js, Express.js
- **Database:** SQLite3
- **Architecture:** Client-Server Architecture
